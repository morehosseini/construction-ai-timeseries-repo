# Supplementary materials

These files support the article *Beyond the Laggard Myth: Time-Series Analysis of AI Job Market Dynamics in Construction*. All tables are generated by `analysis/reproduce_paper.py`; rerunning the script with the licensed data reproduces them exactly.

| File | Contents | Paper section |
|---|---|---|
| [methods_notes.md](methods_notes.md) | Data preparation, sector assignment, and settings and rationale for each method | 3.1–3.6 |
| [sector_mapping.csv](sector_mapping.csv) | Every ANZSIC 2006 subdivision and the group it is assigned to | 3.1, 5.3 |
| [analysis_parameters.csv](analysis_parameters.csv) | All analysis parameters (decomposition, bootstrap settings, seeds, forecasting window) | 3.1–3.6 |
| [seasonality_summary.csv](seasonality_summary.csv) | STL seasonal strength and month-of-year test by sector (values in Table 1) | 4.2 |
| [ccf_bootstrap_stl_remainders.csv](ccf_bootstrap_stl_remainders.csv) | Cross-correlations on STL remainders at lags −6 to +6, with 95% bootstrap bands (Figures 7, 8, 14 and 15) | 4.3, 4.6 |
| [share_ratio_trends.csv](share_ratio_trends.csv) | Construction/Digital and Construction/Traditional ratios: start and end values, OLS slopes and Newey–West 95% intervals | 4.4, 4.7 |
| [forecast_accuracy_ets.csv](forecast_accuracy_ets.csv) | Rolling one-step ETS accuracy by sector (values in Table 2) | 4.5 |
| [sensitivity_excluding_march_2025.csv](sensitivity_excluding_march_2025.csv) | Full panel (51 months) against the panel excluding the partial March 2025 (50 months) | 4.7 |

**Lag convention.** A positive lag means Construction leads the comparator sector: corr(Construction<sub>t</sub>, comparator<sub>t+L</sub>).
